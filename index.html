PROJECT 02 LIVE
AgentEval
Most teams don't know when their AI system breaks — they find out from users, too late. AgentEval turns evaluation into a first-class system layer — automatically scoring outputs, tracking quality over time, and blocking deployments when performance regresses.

The evaluation layer built for the Industrial AI Copilot — and deployable for any LLM system. Runs automated test suites across three evaluation modes (RAG pipeline, single-agent, multi-agent) using custom LLM-as-judge scoring. Current scores: 84.7% RAG · 90.9% single-agent · 90.5% multi-agent with 100% pass rates on agent tiers. Blocks deployments when quality regresses via GitHub Actions CI/CD.

Why this matters Silent quality regression is how production AI systems erode trust. Without automated evaluation, teams only discover degradation after users do. AgentEval closes that gap: every push is scored, every regression is blocked before deployment.

Reliability
Failure Modes & How I Solve Them

Production AI doesn't fail all at once. It fails incrementally, silently — until users notice or costs spike. These are the four failure patterns I've encountered and built defences against.

Incorrect retrieval of critical constraints
Wrong documents surface for high-stakes queries
Solved via
Hybrid BM25 + dense retrieval with Cohere neural reranking — precision over recall in technical domains where a missed constraint is a safety issue
Hallucinated reasoning steps
Model invents logic not grounded in retrieved facts
Solved via
Tool-constrained agent workflows with enforced citation — every reasoning step is traceable to a source, not assumed from parametric memory
Silent performance degradation
System quality drifts undetected after changes
Solved via
AgentEval CI/CD — automated test suites on every push, regression detection blocks deployment if scores drop >5%, dashboard tracks quality trends over time
Untraceable multi-agent outputs
No way to audit which specialist produced a wrong answer
Solved via
Per-specialist result panels in the multi-agent UI + LangSmith trace logging — every specialist's contribution is visible, not merged into a black box

Most AI systems look impressive in demos. They fail quietly in production — wrong retrievals, untracked regressions, outputs nobody can audit. By the time you notice, trust is already gone and the cost is already paid. I build systems that make those failure points visible, measurable, and automatically caught — before users see them, before the cost lands. That's the difference between a demo and a system you can stake a product on.

Retrieval
Hybrid BM25 + dense over pure vector search — sparse excels on exact technical terms (part numbers, fault codes) that embedding models compress poorly. Neural reranking resolves conflicts at the precision boundary.

LangGraph over LangChain LCEL for stateful multi-step agents — graph-based execution gives explicit branching control and deterministic recovery paths that chain-based abstractions can't provide.
